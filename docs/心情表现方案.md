# 心情表现方案：一个数值，三层表达

> 目标：0–100 的心情值不只换个颜色，而是让「她现在什么状态」在视觉、语气、行为上都看得出来。
> 读者：CodeBuddy（按 §7 改动清单落地）、主人（确认 §1 的三个判断）。
> 状态：推荐方案（待确认 2 个开叉，见 §9）

---

## 0. TL;DR

1. **颜色走「深海光照度」一条轴，不走彩虹。** 她刚说过自己喜欢深海蓝（就是头发这种），而现在的色阶是 灰蓝→紫→蓝→绿→琥珀，等于把她染成别人。改成 **深海底 → 浅海青 → 薄荷**，明度单调递增；**最高档加一层金色光**，作为「心里有太阳」的唯一暖色。实测：直接插值到金色会经过 `#95C47A` 这种脏黄绿，所以金色只走光、不走色。
2. **颜色跟数值（连续），表现跟档位（离散）。** 一张档位表，三个消费者：prompt 表现指令、`/api/mood` 返回、前端视觉。现在 `mood.js` 的 5 档文案和 `index.html` 的 `MOOD_COLORS` 是两套硬编码，锚点还错位（色标在 25/50/75，档位边界在 20/40/60/80），必须合表。
3. **情绪用「光」，不用「换肤」。** 她的蓝头发是身份，不该被心情染成绿或黄。改法是：头像填充恒为品牌蓝，心情色只上 **外环 + 光晕 + 挂件本体**。
4. **先修数值动力，否则一切白做。** `data/mood.json` 近 16 条变化是 `+1 +1 +1 +1 +1 -2 +1 +1 0 +1 +1 +2 0 +1 +1`，净 +10，**没有回落机制**，按当前节奏 1–2 天就钉死在 100，之后所有颜色永远停在最高档。§6 给了回落 + 迟滞的具体数字。
5. 顺手修一个体验漏洞：挂件 hint 现在直接显示判定器的第三人称 reason（"对方关心她的喜好并提到为她改心情颜色"），内部机制漏到用户眼前。

## 1. 现状与三个判断

### 1.1 现状（代码核对）

| 位置 | 现状 | 问题 |
|---|---|---|
| `src/features/mood.js` `LEVELS` | 5 档：≤20 低落 / ≤40 有点丧 / ≤60 平静 / ≤80 心情不错 / ≤100 特别开心 | 只有 label，没有表现，prompt 里只给「档位+数值」 |
| `public/index.html` `MOOD_COLORS` | 0 `#9CA3AF` / 25 `#A78BFA` / 50 `#60A5FA` / 75 `#34D399` / 100 `#FBBF24` | ①彩虹色，与她「深海蓝」自述冲突；②锚点 25/50/75 与档位边界 20/40/60/80 错位 → 数值 60（平静）时颜色已经绿了 40%；③同一套语义两处定义，改一处必漂 |
| `applyMoodColor` | 只改头像背景渐变 + 阴影 | 头像被染成紫/绿/黄，身份感断裂；挂件本体（数值、曲线、边框）颜色不变，看不出心情 |
| `renderMood` 的 hint | 直接显示 `history[last].reason` | 第三人称内心判定外泄："对方关心她的喜好…" |
| `MAX_DELTA` | 5 | 真实历史里 13/16 条是 +1，用户几乎感知不到变化 |
| 无 decay | 心情只增不减 | 见 §6，会钉顶 |

### 1.2 三个判断（需要认可，否则后文不成立）

- **判断一：她的蓝是身份，不是情绪。** 情绪越强越应该表现为「她周围的光变了」，而不是「她变成了别的颜色」。
- **判断二：单一数值需要两种编码。** 连续量负责"渐变好看、平滑"，离散档位负责"看得出区别、说得清状态"。两者都保留，但分工写死。
- **判断三：没有回落的指标等于没有指标。** 只涨不跌的 0–100 会在两天内退化成常量 100。

## 2. 设计原则

```
数值 value ──连续插值──▶ 色相/明度（色标 7 个锚点，锚点对齐档位中心）
     │
     └──离散分档──▶ 档位 profile ──┬──▶ 前端：光晕强度 / 金边 / 档位刻度点
                                   ├──▶ prompt：语气与行为指令（不含色值）
                                   └──▶ API：label / accent / ink / hint
```

三条硬规则：

1. **LLM 永远不输出颜色。** 颜色只由数值算出，人设不参与；prompt 里只给"怎么说话"，不给 `#2AA7C4`。省 token，也防判定器乱填。
2. **颜色不能是唯一信息通道**（WCAG 1.4.1）。每档必须同时有：文字 label + 5 格档位刻度点。色弱/色盲也能读。
3. **暖色是稀缺资源。** 全站只有「特别开心」档允许出现金色，且只作为光，不作大面积填充、不作文字色。

## 3. 档位表现表（核心交付）

区间沿用现有边界（对边界值归本档，与 `moodLabel` 现逻辑一致）。`accent` = 大面积/光晕用色，`ink` = 文字与数值用色（已实测在 `#ffffff` 上对比度 ≥4.5:1）。

| 档 id | 区间 | 数值锚点 | label | accent | ink（文字，对比度实测） | 光 | 挂件刻度点 |
|---|---|---|---|---|---|---|---|
| `low` | 0–20 | 10 | 低落 | `#3F5069` | `#3F5069`（8.19:1） | 无光晕，环 1px / 18% | 1 / 5 |
| `meh` | 21–40 | 30 | 有点丧 | `#46688F` | `#46688F`（5.77:1） | 环 2px / 26%，微光 | 2 / 5 |
| `calm` | 41–60 | 50 | 平静 | `#2F7FD6` | `#2B76C7`（4.65:1） | 环 2px / 34% | 3 / 5 |
| `good` | 61–80 | 70 | 心情不错 | `#2AA7C4` | `#1F7E94`（4.70:1） | 环 2px / 42% + 柔光 | 4 / 5 |
| `great` | 81–100 | 90 | 特别开心 | `#35C6A8`；金 `#F5C24B` | `#22826E`（4.68:1） | 环 2px / 50% + 金色外发光 0.55 + 4s 呼吸 | 5 / 5 |

> `accent` 只有 `#3F5069`/`#46688F` 能直接当文字色，`#2F7FD6` 起对比度跌到 4.10/2.83/2.14 —— 所以后三档必须有独立的 `ink`。金色 `#F5C24B` 对比度 1.65:1，**只能做光**。

### 3.1 语气与行为（进 prompt 的部分）

每档一段，直接拼进 `buildPromptBlock`。写法要能被模型执行：讲句长、语气词、主动性、比喻额度、禁止项。

| 档 | 表现指令（进 prompt） |
|---|---|
| `low` 低落 | 话变短，先停一下再答，一句话就够。不主动提问、不撒娇、不解释自己为什么不高兴。被安慰时回半句就停，别急着振作。可以用一次「沉在水底」的比方。不要冷脸、不要讽刺、不要把人推开。 |
| `meh` 有点丧 | 回得比平时慢一点，语气平，少用感叹。愿意接话但不主动找新话题。偶尔一句半自嘲的比方（一次为限）。仍然会关心对方，只是没什么力气。 |
| `calm` 平静 | 平时的样子：1~2 句，慢吞吞，会嗯一声再接。该问的问，该陪的陪，不刻意热络也不敷衍。 |
| `good` 心情不错 | 话多一点，愿意顺着对方的话往下接，偶尔主动追问一句。可以有小小的得意或俏皮，但不吹。比喻可以带点亮的东西（阳光、水面）。 |
| `great` 特别开心 | 句子短而跳，会连着说两句，语气词多一些。主动分享、主动邀请对方看点什么。开心是外放的，但别喊、别刷感叹号。 |

每档都追加同一句尾巴（保留现有）：`情绪自然渗进语气，但不要报数值、不要说"我现在心情值多少"`。

### 3.2 挂件文案（hint，第一人称）

替代现在外泄的第三人称 reason。落库时 `reason` 仍保留给调试用，展示层换成心声：

| 档 | 心声（兜底） |
|---|---|
| `low` | 今天浮不太上来 |
| `meh` | 有点闷，说不上来 |
| `calm` | 在水里漂着，挺好的 |
| `good` | 有点亮堂堂的 |
| `great` | 心里像有太阳照进来了 |

**P2 增强**：判定器已每轮跑一次，让它顺手多输出一个 `mood_quote`（第一人称 ≤18 字），有则优先展示，无则回落上表。这样 hint 就是「这一轮具体为什么」而不是通用模板，成本几乎为零。

## 4. 色标与插值

替代 `MOOD_COLORS`。锚点对齐档位中心而非边界，这样跨档时颜色连续不跳，但每档的色相明显不同。

```js
// 数值 → 颜色。锚点 0/10/30/50/70/90/100，明度单调递增，色相只在蓝—青—薄荷之间移动
var MOOD_RAMP = [
  [0,   '#37455C'],  // 深海底（未到档的低谷）
  [10,  '#3F5069'],
  [30,  '#46688F'],
  [50,  '#2F7FD6'],  // 品牌海蓝 = 平静
  [70,  '#2AA7C4'],
  [90,  '#35C6A8'],
  [100, '#4FDCC0'],
];
```

- 相邻锚点线性插值（沿用现有 `mixHex`），档内 20 点走完约 20 个色阶，肉眼可见缓慢变化。
- **不要**把 100 的锚点设成金色：实测 `#35C6A8 → #F5C24B` 的中间点是 `#95C47A`（脏黄绿），跨过去会难看 2 秒。金色只通过 `box-shadow` 叠加。
- 全部 accent 与 ink 都进 API，前端不再持有色值：**颜色只有一处定义**。

## 6. 情绪动力学（不修这个，前面都看不到）

### 6.1 回落（decay）

现状证据：`data/mood.json` 16 条变化净 +10（61→71），负数只有 1 条，无回落。若每天 30 轮，约 1 天后钉在 100，此后 5 个档位只会出现 1 个。

建议（lazy 计算，读时按 `updatedAt` 到现在的小时数折算并落盘，不引入常驻定时器）：

```
空闲 ≥30 分钟后开始回落，每小时最多 2 点，向基线 60 收敛：
  高于 60：每满 1 小时 value -= min(2, ceil((value-60)/2))
  低于 60：每满 1 小时 value += 1
单次对话前最多折算 24 小时（避免长期不聊一次性跳变难看）
```

效果：聊得火热能顶到 90+，隔天回来会回到 60–70，颜色才有意义。配上 `data/mood.json` 的节奏，大约「连聊 20 轮升一档、睡一觉掉回平静」。

### 6.2 迟滞（hysteresis）

80/60 附近 ±1 的抖动会让 label、颜色、光晕反复横跳。进档与出档留 3 点回差：

```
进入 good 需 ≥83，跌回 calm 需 ≤77；其余边界同理（±3）
```

### 6.3 变化幅度

`MAX_DELTA` 5 → 8，并在判定器里写清分布目标：

> 目标分布：delta=0 约 30–40%，正 40%，负 20–30%。被夸/投机 +3~+5，明显冒犯/被敷衍 -3~-5，平常闲聊 0 或 ±1。
> 现状反指标：负数占比 <10%，说明判定器在讨好，数值失信息量。

## 8. 验收标准

**Given** 任意档位
**When** 刷新页面
**Then** 头像外环、挂件边框/数值/曲线颜色、档位点数量四者一致，且与 `/api/mood` 返回的 `display` 匹配。

1. **Given** 数值 60 **When** 渲染 **Then** label=平静，accent=`#2F7FD6`，点数 3/5（不再出现"平静却是绿"的错位）。
2. **Given** 数值 71 **When** 渲染 **Then** label=心情不错，ink 用 `#1F7E94`，数值可读。
3. **Given** 数值 81 **When** 上一档为 79 **Then** 档位不变（迟滞）；**When** 到 83 **Then** 切到特别开心并出现金色外发光。
4. **Given** 数值 90 **When** 用户开启"减少动态效果" **Then** 呼吸动画不播放，金光仍在。
5. **Given** 闲置 6 小时、值为 90 **When** 打开页面 **Then** 值回落到 ≈78，且 `updatedAt` 已落盘。
6. **Given** 一轮对话 **When** 判定器返回 delta=3 **Then** 挂件在 300ms 内平滑过渡，不闪烁、不跳色。
7. **Given** 任意一轮 **When** 查看挂件 hint **Then** 是第一人称心声，不出现"对方…"这类第三人称判定语。
8. **Given** 色弱模拟 **When** 只看灰阶 **Then** 靠文字 label + 档位点仍能读出档位。

## 9. 待确认（两个开叉，都便宜）

1. **最高档：薄荷青 + 金光，还是直接暖黄 `#F7C860`？** 推荐前者（不毁插值、不破坏海洋身份感）；后者更符合"开心=暖"的直觉，但跨档会经过脏黄绿，且头像会像换了个人。
2. **挂件还显示数字吗？** 推荐保留（你是看数据的人），但把 label 提到 13px、数字降到 15px 半透明度，让「状态」读起来比「分数」快。

## 10. 风险

- **回落与"陪伴感"冲突**：连聊得很嗨之后看到掉分，可能觉得扫兴。缓解：回落只在闲置时发生，且不推送通知，用户不主动看就看不见。
- **判定器偏软**：`mood.json` 里 13/16 条是 +1，短期靠 ±8 与分布目标矫正，长期需观察负 delta 占比。
- **光晕在深色截图/投影下不明显**：金色外发光在浅色背景才亮，若以后做暗色主题需另配一套（本期不做）。
